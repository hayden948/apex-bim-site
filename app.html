Submittal → Family pipeline console

Drive the hosted Apex API end-to-end: upload a submittal PDF, run AI extraction, review & approve into the family library, QA-validate, queue RFA generation for the Revit worker, and download the built family.

Connection

Sign in with your Apex account — or paste an apx_… service token / the project publishable key. Credentials stay in this browser (localStorage).

1Upload a submittal PDF

Max 30 MB. The file lands in private storage; nothing is public.

2Run AI extraction

Claude reads the PDF and returns family name, category, box geometry, and engineering parameters with per-field confidence. Requires the ANTHROPIC_API_KEY secret on the API.

3Approve → library

Converts the reviewed extraction into an AFIS 1.0 document (metric, NEC 110.26 clearance zone auto-added for electrical gear) and files it in the family library.

4Family library

Validate runs the Doc 8 QA engine; Queue RFA is QA-gated (no certificate, no export) and is picked up by the Process Queue button in the Revit plugin; Download serves the built .rfa once the worker delivers it.

Apex pipeline console — talks directly to the hosted Apex API v1.
